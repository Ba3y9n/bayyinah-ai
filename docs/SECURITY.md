# دليل الأمان وحماية البيانات | Security & Compliance Guide

> **إجراءات الأمان والسرية، حماية المفاتيح، والوقاية من الهجمات في منصة بيّنة AI**

---

## 1. بروتوكول سرية المفاتيح الصارمة (Zero Key Exposure)

- **الحفظ الحصري بالخادم (Server-Side Only):**
  تُخزن جميع المفاتيح الحساسة (`GEMINI_API_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `DATABASE_URL`) حصراً داخل المتغيرات البيئية بالخادم الخلفي (`backend/.env`).
- **حظر التصدير والتسريب:**
  يُحظر كلياً تمرير أي مفتاح إلى كود الواجهة الأمامية (Frontend)، أو تضمينه في حزم البناء (Vite Bundle)، أو إظهاره في ترويسات الشبكة أو كائنات الاستجابة للمستخدم.
- **إخفاء الأخطاء الحساسة (Error Sanitization):**
  يقوم الخادم بتنقية جميع رسائل الخطأ من أسماء المتغيرات، مسارات الملفات الداخلية، أو مفاتيح الاتصال قبل إرسالها للعميل.

---

## 2. درع الحماية ضد هجمات SSRF (Anti-SSRF Protection)

- يتم فحص كل رابط خارجي باستخدام دالة `is_safe_url()` قبل إجراء أي طلب شبكي.
- حظر العناوين المحلية (Loopback)، الشبكات الداخلية الخاصة (RFC 1918)، ونقاط نهاية خدمات بيانات التعريف السحابية (Cloud Metadata Services: `169.254.169.254`).
- حظر البروتوكولات غير الآمنة (`file://`, `ftp://`, `gopher://`).

---

## 3. تحديد معدل الطلبات (Rate Limiting Middleware)

- يطبق الخادم طبقة برمجية وسيطة لمراقبة وتحديد وتيرة الطلبات:
  - **الحد الأقصى:** 60 طلباً في الدقيقة لكل عنوان IP (`60 requests / 60 seconds`).
  - **معالجة التجاوز:** إرجاع استجابة فورية برمز الحالة HTTP 429 ورسالة توجيهية بالعربية دون استهلاك موارد الخادم أو الذكاء الاصطناعي.

---

## 4. تنقية المدخلات والحصانة ضد الحقن (Injection Prevention)

- **SQL Injection:** استخدام SQLAlchemy ORM والمعاملات المجهزة (Parameterized Queries) حصراً لمنع أي حقن لقواعد البيانات.
- **Prompt Injection:** تطبيق طبقات تطبيع مسبقة (Input Normalization) وفصل صارم بين مدخلات المستخدم وقوالب النظام الموجهة للنموذج (System Instructions).
- **Cross-Site Scripting (XSS):** تنقية النصوص وتجريدها من وسوم HTML الخطرة قبل عرضها في متصفح العميل.

---

## 5. سجل التدقيق الرقابي (Comprehensive Audit Logging)

- يتم تدوين كل عملية استعلام وتحقق ومحادثة في جدول `audit_logs` في قاعدة بيانات Supabase.
- يشمل السجل: معرف الطلب، المتن المفحوص، المصادر والقطع المسترجعة، النتيجة المصدرة، النموذج المستخدم، وزمن الاستجابة التفصيلي.
