# Database Architecture

Bayyinah AI relies on a production-grade **Supabase PostgreSQL** database.

### Core Features
- **pgvector:** Used to store and query dense semantic embeddings (generated by Gemini `text-embedding-004`).
- **Hybrid Search:** The `retrieval_agent.py` leverages both vector similarity search (cosine distance) and traditional keyword filtering to ensure accurate recall from classical Arabic texts.

### No Silent Local Fallbacks
In Production, Bayyinah AI enforces a strict database connection. 
- If the Supabase PostgreSQL database is unreachable, the API will intentionally `FAIL` and return a clear `503 Service Unavailable`.
- There is **no silent fallback** to local SQLite. This ensures that the application behaves predictably and doesn't serve unverified data from an incomplete local cache.
