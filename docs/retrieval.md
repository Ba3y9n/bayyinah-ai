# محرك البحث الهجين والانصهار الترتيبي (Hybrid Retrieval & RRF)
## خوارزميات الاسترجاع والتصفية الفئوية في بيّنة AI

---

### 1. قنوات الاسترجاع الأربع (The 4 Retrieval Channels)
لا تعتمد بيّنة AI على البحث الدلالي أو الكلمات المفتاحية وحدها، بل تدمج 4 قنوات بحث متوازية:

1. **المطابقة اللفظية الدقيقة (Exact Match)**: مطابقة متطابقة لمتون الأحاديث والآيات وأرقام الأبواب، وتمنح وزناً استدلالياً حاسماً.
2. **البحث بالنصوص والكلمات المفتاحية (Keyword / Token Search)**: استعلام عبر الكلمات الدالة بعد التطبيع العربي وحذف الزوائد اللفظية.
3. **البحث الدلالي المتجهي (Semantic Search via Embeddings)**: حساب التشابه الدلالي والسياقي لتقريب النصوص المترادفة في المعنى.
4. **التصفية الفئوية المسبقة (Metadata Category Filtering)**: تضييق نطاق الاستعلام تلقائياً بحسب نوع الادعاء (مثل حصر استعلام صحة الأحاديث في فئة `HADITH`).

---

### 2. الانصهار الترتيبي المتبادل (Reciprocal Rank Fusion - RRF)
تُدمج نتائج القنوات المختلفة بالمعادلة المعيارية:
$$RRF\_Score(d) = \sum_{m \in M} w_m \cdot \frac{1}{k + rank_m(d)}$$
حيث:
- $k = 60$ (معامل الضبط لتفادي التحيز المفرط للرتب الأولى).
- $w_{exact} = 1.5$ (وزن المطابقة الدقيقة).
- $w_{semantic} = 1.2$ (وزن التقارب الدلالي).
- $w_{keyword} = 1.0$ (وزن تطابق الكلمات).

---

### 3. تقييم كفاية الدليل وتصنيف النتائج (Evidence Ranking & Decision)
بعد احتساب درجات RRF، تُصنف الأدلة إلى:
- `DIRECT_SUPPORT`: دعم مباشر وتطابق لفظي أو سياقي قطعي.
- `PARTIAL_SUPPORT`: دعم جزئي أو شرح إضافي.
- `CONTEXT`: سياق عام أو بيئة استدلالية.
- `CONTRADICTING`: تصريح المصدر بضعف أو بطلان أو خطأ اللفظ.
- `NO_MATCH`: عدم العثور على ما يثبت الادعاء، فيطبق النظام فوراً مبدأ **الامتناع التحفظي (Abstention)** لتجنب الهلوسة.
