# سياسة البيانات والخصوصية | Data Policy
> **بيّنة AI — سياسة جمع وحفظ وتداول البيانات**

---

## 1. الحد الأدنى لجمع البيانات (Minimal Data Collection)
- **لا جمع للبيانات الشخصية الحساسة:** لا تطلب المنصة تسجيل حساب إجباري، ولا تجمع أسماء المستخدمين أو أرقام هواتفهم أو مواقعهم الجغرافية.
- **الصور المرفوعة مؤقتة:** تُعالج الصور المدخلة لأغراض استخراج النص (OCR) أثناء جلسة التحقق الآنية فقط، ولا تُخزن بشكل دائم على الخوادم.
- **المعرفات المجهولة (Anonymized Identifiers):** تُربط عمليات التحقق بمعرفات عشوائية (UUID) لأغراض التتبع الاستدلالي دون أي ربط بهوية المستخدم.

---

## 2. سياسة بيانات الاختبار (Synthetic & Test Data)
- بيانات حزمة التقييم المعياري الـ 30 حالة هي بيانات اختبار عامة أو اصطناعية (Synthetic/Anonymized).
- لا تحتوي أي من حالات الاختبار على معلومات شخصية أو وقائع أسرية حقيقية لأشخاص محددين.

---

## 3. حماية الأسرار ومفاتيح الـ API (Secrets Management)
- تُحفظ جميع مفاتيح الوصول والربط (`GEMINI_API_KEY`, `SUPABASE_KEY`) عبر متغيرات البيئة (`.env`).
- يُحظر كلياً إيداع أي مفتاح أو سر تقني داخل مستودع الأكواد (GitHub).
- يتم توفير ملف `.env.example` كقالب فارغ للإعداد المحلي فقط.

---

## 4. الاحتفاظ بالبيانات وسجلات البحث (Data Retention & Logs)
- تُسجل استعلامات البحث لأغراض رصد أداء محرك Hybrid Search وتحسين دقة المطابقة اللفظية فقط.
- تخلو سجلات النظام (`search_logs`) من أي بيانات هوية شخصية للمستخدمين.
