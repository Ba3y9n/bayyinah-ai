# سياسة التراخيص وحقوق الاستخدام (Source Licensing Policy)
## حماية الملكية الفكرية والحدود القانونية لإعادة النشر في بيّنة AI

---

### 1. مبدأ الفصل القانوني الصارم
تلتزم منصة **بيّنة AI** بقاعدة جوهرية تفرق بوضوح بين:
1. **مصدر معتمد كمرجع علمي**: جهة موثوقة نعتد بتخريجها وأحكامها.
2. **محتوى تم تخزينه داخل قاعدة المعرفة**: نصوص تم فحصها وتخزينها بأمان.
3. **محتوى مسموح بإعادة نشره وتوزيعه**: نصوص تحت الملكية العامة أو رخص الاستخدام المفتوح.
4. **مصدر قيد مراجعة حقوق الاستخدام**: مصادر تقتصر عملياتها على المقتطفات والإحالة للرابط الأصلي.

> **«ورود المصدر في الحزمة العلمية للتحدي لا يعني تلقائياً جواز نسخ أو إعادة نشر كامل محتواه في قاعدة البيانات.»**

---

### 2. حالات التراخيص (License Status)
- `VERIFIED`: تم التحقق قانونياً من وثيقة الاستخدام أو كونه ضمن الملكية العامة للتراث المحقق.
- `PENDING_VERIFICATION`: المصدر معتمد كمرجع، ولكن وثيقة إعادة الاستخدام التقني قيد المراجعة؛ ويقتصر التعامل معه على **مقتطفات الاستدلال المحدودة (Limited Excerpts) والإحالة بالرابط الأصلي**.
- `RESTRICTED`: مقيد وفق ضوابط محددة.
- `UNKNOWN`: حالة مجهولة تعامل معاملة المنع من التخزين الكامل.
- `NOT_APPLICABLE`: نصوص مقدسة أو وثائق رسمية لا تخضع لحقوق النشر الفردية.

---

### 3. مصفوفة العمليات المسموحة (Allowed Operations Matrix)
لكل مصدر بنية بيانات صريحة تحدد صلاحياته البرمجية:
```json
{
  "METADATA_ONLY": true,
  "SEARCH_SNIPPETS": true,
  "INDEX_CONTENT": true,
  "STORE_CONTENT": false,
  "QUOTE_LIMITED": true,
  "DISPLAY_EXCERPT": true,
  "LINK_TO_SOURCE": true,
  "TRANSLATE": false,
  "DERIVE_EMBEDDINGS": true
}
```
المصادر التي تحمل `STORE_CONTENT: false` يُحظر على النظام تخزين كتبها كاملة، ويُكتفى بالفهارس الوصفية ورابط الإحالة المباشر.
