# خط أنابيب معالجة الوسائط المتعددة والفيديو | Multimodal & Video Pipeline

> **التوثيق التقني لمعالجة الصور، المقاطع المرئية، واستخدام Gemini Files API في منصة بيّنة AI**

---

## 1. نظرة عامة (Overview)

يدعم نظام **بيّنة AI** استقبال وتحليل الوسائط المتعددة (صور، ملصقات واتساب، إنفوجرافيك، مقاطع فيديو قصيرة، مقاطع تيك توك ويوتيوب) لتحويلها إلى ادعاءات نصية محددة قابلة للتحقق المنهجي.

---

## 2. معالجة الصور والنصوص البصرية (Image OCR Pipeline)

- **المحرك:** Google Gemini 3.8 Flash (`gemini-3.8-flash`) عبر الاستدعاء المباشر متعدد الوسائط (Multimodal Inference).
- **سياسة التفكير:** `thinking_level='medium'` لدقة قراءة الخطوط العربية المتنوعة (النسخ، الرقعة، الخطوط المصحفية).
- **التحكم والشفافية التفاعلية:**
  عند رفع الصورة، يظهر النص المستخرج في صندوق إدخال فوري على الواجهة، مما يتيح للمستخدم مراجعة الكلمات أو تصحيح أي خطأ إملائي قبل إطلاق مسار الفحص.
- **الحد الأقصى لحجم الصورة:** 20 ميجابايت (`MAX_IMAGE_MB=20`).

---

## 3. معالجة مقاطع الفيديو الكبيرة (Large Video Pipeline & Files API)

بالنسبة لمقاطع الفيديو والصوت التي تتجاوز حمولة الطلب المباشر:

```
[ ملف الفيديو المرفوع (حتى 100 MB) ]
               │
               ▼
1. الرفع السحابي إلى Google Gemini Files API
   client.files.upload(file=video_path)
               │
               ▼
2. مراقبة حالة المعالجة (Polling Loop)
   فحص حالة الملف حتى الوصول إلى 'ACTIVE'
               │
               ▼
3. التحليل الشرعي والزمني بـ Gemini 3.8 Flash
   - تفريغ المتن الصوتي (Audio Transcript).
   - قراءة النصوص المكتوبة على الشاشة (Visible Text / On-Screen Titles).
   - استخراج الادعاءات المحددة مع الطوابع الزمنية (Timestamps).
   - رصد الآيات والأحاديث المقتبسة في المقطع.
               │
               ▼
4. التوجيه لمحرك التحقق المبني على الأدلة
   تمرير كل ادعاء مستخرج إلى محرك الاسترجاع الهجين.
```

---

## 4. التحكم بالطوابع الزمنية (Timestamp Range Filtering)

توفر الواجهة إمكانية تحديد نافذة زمنية للمقطع (مثل: `00:15 - 00:45`):
- يركز النظام تحليله على الجزء المحدد دون تشتيت الانتباه في باقي المقطع.
- يربط كل ادعاء مستخرج بالطابع الزمني الدقيق لظهوره في الفيديو لتسهيل المراجعة على الحكام والمستخدمين.

---

## 5. ضوابط الأمان والحدود القصوى (Safety Limits)

| نوع الوسائط | الحد الأقصى للحجم | الامتدادات المدعومة | طريقة المعالجة |
| :--- | :--- | :--- | :--- |
| **الصور والملصقات** | 20 MB | `.jpg`, `.jpeg`, `.png`, `.webp` | Gemini 3.8 Flash Multimodal OCR |
| **المقاطع المرئية** | 100 MB | `.mp4`, `.mov`, `.webm`, `.avi` | Gemini Files API + Audio Transcription |
| **المستندات الرقمية**| 50 MB | `.pdf` | Structured Document Ingestion |
